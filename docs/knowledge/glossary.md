# Glosario de la interfaz

| Término | Cuándo se usa |
| --- | --- |
| **Biblioteca** | Archivos de la marca disponibles para reutilizar, como imágenes, vídeos, audio y documentos. |
| **Recurso** | Un archivo que se adjunta a una publicación o se usa en un diseño. |
| **Plantillas de publicación** | Contenido reutilizable de una publicación, con texto, recursos y destinos. La acción que lo registra se llama «Guardar como plantilla». |
| **Plantillas de diseño** | Diseños reutilizables del Estudio. |
| **Papelera de publicaciones** | Publicaciones borradas que se pueden restaurar durante el plazo de retención. |
| **Papelera de diseños** | Diseños archivados que se pueden restaurar desde el Estudio. |
| **Identidad de marca** | Colores, tipografías, logotipos y pautas de comunicación de la marca. |
| **Correo** | Una dirección o un mensaje de correo electrónico, según el contexto. |
