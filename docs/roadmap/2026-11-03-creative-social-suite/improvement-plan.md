# Plan de construcción de la suite

Se conserva la base social y se añade el estudio nativo. El alcance autorizado incluye todas las funciones identificadas de referencia; el ledger y la matriz evitan reducirlo silenciosamente a un MVP.

1. Inventario REA/observación/documentación y contrato UI/API/MCP. Revisar las métricas en paralelo, con RED y causa demostrada antes de cambiar cálculos.
2. Fundaciones por marca: documentos, carpetas, kit, recursos, revisiones y aislamiento. API JSON y servicios reutilizables. Autoguardado con conflicto explícito.
3. Editor gráfico con Fabric 7.4 como adaptador, formato propio, componentes Vue accesibles y herramientas reales. Exportación por página y recuperación en el compositor.
4. Render y trabajos accesibles por API/MCP; exportaciones trazables, plantillas, tipografías, colaboración, transformaciones y funciones creativas avanzadas.
5. Vídeo/audio, documentos, presentaciones, web e IA como módulos propios, con validación audiovisual y de proveedor; comprobar licencias de recursos.
6. Brechas Metricool: media por destino, previews, opciones, conectores, aprobación/manual/recurrencias/lotes, inbox y profundidad de reporting/SmartLinks/Ads.
7. Consistencia integral de marcas, métricas, permisos, rendimiento, accesibilidad y despliegue. Revisiones adversariales y QA por fase. Commits/PR autorizados; no merge ni publicación externa automática.

Cada bloque pasa pruebas focales; una regresión amplia se ejecuta cuando el bloque afecte contratos compartidos. La investigación de productos externos usa REA para runtime cuando es accesible y fuentes oficiales para funciones que la cuenta gratuita no permite observar. No se afirma observación de una pantalla bloqueada ni paridad sin prueba.
